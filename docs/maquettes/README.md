# Maquettes de référence (exports Figma)

Planches extraites des fichiers Figma de l'équipe (inscription, questions d'onboarding, parcours étudiant, parcours mentor).
Pour construire ou retoucher un écran avec Claude Code, cite la planche : `/ecran … (voir docs/maquettes/parcours-etudiant-2.jpg)`.

Pour une fidélité maximale, exporte l'écran voulu depuis Figma en PNG @2x et glisse-le directement dans Claude Code.
